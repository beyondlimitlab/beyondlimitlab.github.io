# Beyond Limit Lab Portfolio

Ready for GitHub Pages.

## What to replace
1. In `index.html`, replace each project card's `href="#"` with the real App Store, demo, GitHub, or project URL.
2. Replace `hello@example.com` with your email.
3. Replace placeholder descriptions/status/tags.
4. Put real cover images in `/images`. You can then change a cover rule in `style.css`, e.g.:
   `background: url("images/abouttime.webp") center/cover;`

The layout is responsive: 3 columns on desktop, 2 on tablet, 1 on mobile.
